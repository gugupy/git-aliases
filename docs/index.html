Manage your global Git aliases

An interactive command-line tool for managing your global Git aliases. Pick from a set of useful built-in aliases, add your own, and remove the ones you don't use, all without editing ~/.gitconfig by hand.

Download git aliases

Single binary, about 4 MB. Needs only Git. Each entry downloads from the latest release.

Install

Rename the download to git-aliases (git-aliases.exe on Windows) and put it in a folder on your PATH. On macOS or Linux:

$ chmod +x git-aliases-*
$ mv git-aliases-* /usr/local/bin/git-aliases
$ git aliases

Git runs any program named git-<name> on your PATH as git <name>, so git aliases and git-aliases both work. If macOS blocks the binary:

$ xattr -d com.apple.quarantine /usr/local/bin/git-aliases

With Go installed, you can also build from source:

$ git clone https://github.com/gugupy/git-aliases.git
$ cd git-aliases
$ go install .

What it does

What would you like to do?

Select from a list of common shortcuts and add them in one step. Space toggles an item, Ctrl+A selects all or none. The full list is below.

Name an alias, pick a Git command from a searchable list (press /), and edit it before saving. It previews the command and asks before replacing an alias that runs something different.

Filter your global aliases by name or command, then remove the ones you select.

Esc on the main menu, or Ctrl+C anywhere. Aliases you saved are already in your global Git configuration, so they work in every repository.

↑/↓ move·Enter select·Esc quit

Usage

$ git aliases              # start the interactive CLI
$ git aliases -h           # usage (--help opens Git's man pages)
$ git aliases --version

Built-in aliases

After installing them all, list them the way Git stores them (output aligned here for reading):

$ git config --global --get-regexp '^alias\.'
Built-in aliases and the Git command each one runs
AliasCommand
alias.ststatus --short --branch
alias.cocheckout
alias.brbranch
alias.cpcherry-pick
alias.cicommit
alias.lastlog -1 HEAD
alias.lglog --oneline --graph --decorate --all
alias.spstash push
alias.sppstash pop
alias.slstash list
alias.theirscheckout --theirs -- .
alias.unstagereset HEAD --

So git st runs git status --short --branch. During a merge conflict, git theirs takes the incoming side for every conflicted path; review the result and run git add when ready.
