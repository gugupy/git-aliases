Manage your global Git aliases

An interactive command-line tool for managing your global Git aliases. Pick from a set of useful built-in aliases, add your own, and remove the ones you don't use, all without editing ~/.gitconfig by hand.

Download the latest release Single binary, about 4 MB. Needs only Git.

Install

Rename the download to git-aliases (git-aliases.exe on Windows) and put it in a folder on your PATH. On macOS or Linux:

chmod +x git-aliases-*
mv git-aliases-* /usr/local/bin/git-aliases
git aliases

Git runs any program named git-<name> on your PATH as git <name>, so git aliases and git-aliases both work. If macOS blocks the binary, run xattr -d com.apple.quarantine /usr/local/bin/git-aliases.

With Go installed, you can also build from source:

git clone https://github.com/gugupy/git-aliases.git
cd git-aliases
go install .

What it does

  • Built-in aliases: select from a list of common shortcuts and add them in one step.
  • Custom aliases: name an alias, pick a Git command from a searchable list, and edit it before saving. It shows a preview and asks before replacing an existing alias.
  • Browse and remove: filter your global aliases and remove the ones you select.
  • Global config: aliases are written to your global Git configuration, so they work in every repository.

Usage

git aliases              # start the interactive CLI
git aliases -h           # usage
git aliases --version

In multi-select lists, press Space to toggle an item, Ctrl+A to select all or none, and Enter to confirm. Esc returns to the main menu and Ctrl+C quits.
